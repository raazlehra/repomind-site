# RepoMind Private Beta

RepoMind is currently private beta software. Access is limited and manually reviewed.

## Beta Access Workflow

1. A developer submits the public Request Beta Access issue form.
2. The maintainer reviews the request manually.
3. Approval is not automatic.
4. Approved testers receive access instructions separately.
5. The tester installs the current approved beta using the instructions they receive after approval.
6. The tester uses RepoMind on repositories they own or are authorized to use.
7. Feedback should avoid proprietary code, credentials, secrets, tokens, customer data, and private repository details.

## Who We Are Especially Interested In

- Developers working with Python / FastAPI.
- Developers working with JavaScript / TypeScript / React.
- Developers working with Kotlin / Android.
- Developers working with mixed-language repositories.
- Developers working with larger repositories.
- Developers using Codex, GitHub Copilot, Claude, Cursor, or other coding-agent workflows.

These examples do not imply partnerships or endorsements.

## Approval

Beta access is limited and may be revoked. The public request form starts the review process only. It does not grant product access, repository access, collaborator invitations, payment processing, or private support infrastructure.

If access is approved, any private repository invitation or setup instruction will be sent separately by the maintainer.

## Safety Expectations

Test RepoMind only on repositories you own or are authorized to use. Do not paste proprietary source code, credentials, API keys, tokens, private keys, internal URLs, customer data, or other sensitive information into public issues.
