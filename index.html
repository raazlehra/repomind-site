The problem

Coding work repeatedly rediscovers the same repository facts.

Developers and agents need structure, symbols, dependencies, callers, tests, routes, and change context before they can make or review a focused edit.

RepoMind makes that evidence persistent and reusable while keeping the working tree authoritative and human review in the loop.

Language support

Strong support where extraction is deepest; conservative support elsewhere.

First-class extraction: Python, JavaScript, TypeScript, JSX, and TSX. Conservative fallback structural extraction: Java, Go, Rust, C#, C, and C++. Other recognized files receive basic recognition and are not presented as equal-maturity support.

Test impact

Plan review and testing from static evidence—not guesswork presented as certainty.

RepoMind analyzes changed files or areas against indexed relationships and returns a bounded, inspectable starting point for test planning.

How RepoMind works

A bounded local path from repository to useful evidence.

  1. Repository
  2. Eligible files + static analysis
  3. Local SQLite index
  4. Bounded context + change-impact evidence
  5. CLI or local MCP
  6. Developer or coding agent
Source remains authoritative. RepoMind output guides discovery and review; inspect the relevant source and evidence before acting.

Do not use plain pip install repomind.

The package with that name on PyPI is a different project. Install the wheel attached to the RepoMind GitHub Release and verify it as described in the installation guide.

Privacy and security

Local core, explicit downstream trust boundaries.

During normal analysis, RepoMind core locally reads repository files, has no normal telemetry or external-AI-API path, does not directly upload source, and does not execute recommended repository test commands.

Read the canonical security model
  • MCP clients and coding agents are separate trust boundaries. They may send RepoMind-returned metadata, command data, or requested snippets to their configured provider.
  • The local .repomind index may contain paths, symbols, signatures, short docstrings, relationships, Git state, and repository memory.
  • Manual memory is user-provided and may itself contain sensitive content.
  • Treat the local index and memory with the same access controls as the repository.

FAQ

Short answers, careful claims.

Is RepoMind free and open source?

Yes. The current RepoMind core is public under Apache-2.0. Download the current release directly from GitHub.

Is b11 stable?

v2.0.0b11 is a prerelease hardening beta, not a production-stability promise. Review the release notes and use normal care with pre-release developer tooling.

How do I install it?

Download the wheel from the exact v2.0.0b11 release and follow the installation guide.

Why shouldn’t I use pip install repomind?

The repomind package name on PyPI belongs to a different project.

What platforms and Python versions are release-tested?

The b11 release is tested on Linux and Windows with Python 3.11, 3.12, and 3.13.

Does RepoMind upload source?

RepoMind core does not directly upload repository source during normal analysis. Local clients, agents, and anything you choose to share are separate boundaries.

What can an MCP client or AI provider receive?

A client may send RepoMind-returned metadata, recommended-command data, or requested bounded snippets to its configured provider. Review that client and provider before using sensitive code.

Does test-impact execute tests?

No. RepoMind returns recommended commands as data; a developer, agent, or CI system decides whether to run them.

Is test-impact exhaustive?

No. It is bounded static analysis and can miss dynamic or runtime behavior. Review evidence, unknown areas, confidence, and completeness/truncation metadata.

Where is the local index and memory stored?

Repository-local data is stored under .repomind/, with the SQLite index at .repomind/index.sqlite3. Treat it as potentially sensitive metadata.

What does init --force do to manual memory?

It rebuilds RepoMind’s SQLite index and removes manual memory stored only in that database. Export or record manual facts first if they must be preserved.

What is the design-partner pilot?

A paid, bounded evaluation with one team, one repository, up to 10 representative PRs, about two weeks, local execution, and human review of whether the output adds useful information.

Is RepoMind Pro or a hosted SaaS available today?

No. The design-partner pilot is not a mature subscription or a generally available hosted product.
