The problem

Coding agents keep rediscovering the same repository facts.

Agents often need to rediscover structure, important files, symbols, dependencies, callers, tests, routes, and architecture facts before they can make a focused edit.

RepoMind makes that repository intelligence persistent and reusable, while keeping the source tree authoritative.

Privacy model

Local by default, with clear boundaries.

  • RepoMind stores its intelligence index in local SQLite under the repository.
  • RepoMind locally reads and indexes repository files.
  • Normal indexing and retrieval do not upload source code.
  • RepoMind does not send telemetry.
  • No external AI API is required for normal operation.
  • The source tree remains authoritative; RepoMind output is discovery guidance.

FAQ

Short answers, careful claims.

What is RepoMind?

RepoMind is a local-first repository intelligence layer for AI coding agents. It indexes repository metadata, symbols, relationships, architecture facts, and memory into a local SQLite cache.

Does RepoMind upload my code?

RepoMind does not upload repository source during normal operation. Validation reports remain local until a tester chooses to share sanitized results.

Does RepoMind require an AI API?

No external AI API is required for normal indexing or retrieval.

Does RepoMind replace Codex/Copilot/Claude?

No. RepoMind is not a coding agent. It provides local repository context that agents and developers can inspect before editing source.

What is Repository Memory?

Repository Memory stores durable local facts with source evidence, category, confidence, timestamps, source type, and freshness status.

Why is Audit more expensive than Setup?

Audit includes setup plus human architecture analysis, repository mapping, validation, written findings, prioritized recommendations, and findings handoff.

Is RepoMind production-ready?

RepoMind is private beta software. Developers should use normal care with pre-release developer tools.

Does RepoMind guarantee AI credit savings?

No. Token measurements are local estimates, not provider billing tokens, account credits, or guaranteed savings.

How do I join the private beta?

Submit the public beta access issue form. Requests are reviewed manually.

How do I receive beta access after approval?

Approved testers receive access instructions separately after maintainer review.

Does RepoMind automatically approve beta requests?

No. Beta access is limited, manual, and may be revoked.

Is a call included with the audit?

A findings handoff is included. A short walkthrough can be arranged if needed.
