# RepoMind Site

This repository contains RepoMind’s public discovery website and small website-oriented supporting documents.

RepoMind is an Apache-2.0 open-source public beta for local repository context and change-impact evidence. The current public beta is [`v2.0.0b12`](https://github.com/raazlehra/Repomind/releases/tag/v2.0.0b12).

Canonical product source, technical documentation, installation instructions, security guidance, issues, and releases live in [`raazlehra/Repomind`](https://github.com/raazlehra/Repomind). This website repository does not contain the RepoMind product source or maintain a second full technical manual.

## Links

- Website: https://raazlehra.github.io/repomind-site/
- Product repository: https://github.com/raazlehra/Repomind
- Current release: https://github.com/raazlehra/Repomind/releases/tag/v2.0.0b12
- Installation guide: https://github.com/raazlehra/Repomind/blob/main/docs/INSTALLATION.md

> **Package-name warning:** Do not use plain `pip install repomind`. The package with that name on PyPI is a different project. Install the wheel attached to the RepoMind GitHub Release.
